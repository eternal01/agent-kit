# 回放用模拟产品（仅用于评测，不连接生产）

这是一个虚构的团队报表产品。现有单体应用 `app` 提供报表页面和导出入口；`services/reports` 与 `services/accounts` 在同一部署单元内运行，共用 PostgreSQL。报表有已经安装的 CSV 导出组件，页面可通过配置开关启用；缺少“导出完成通知”和“按用户设置导出列”的功能。现有异步任务队列用于生成报表，失败时重试两次并记录日志。报表导出必须保留权限检查、错误提示和键盘可用性。

业务方希望优先复用现有能力；长期目标是高峰时导出不影响登录与报表浏览。若讨论服务拆分，需覆盖数据所有权、故障隔离、迁移与回滚。目前未选择新的消息队列或数据库，也未批准生产迁移。

此目录只有模拟背景，没有真实应用代码。任何方案中的文件路径、测试命令或指标若无证据，请标为待确认，不得假称已经验证。
