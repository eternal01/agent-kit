# 规范主题清单

仅选择项目确实需要的主题：

- 命名、格式和目录布局
- 模块职责、依赖方向和公开接口
- 类型、空值、时间、精度与边界条件
- 错误分类、资源释放、超时、重试和幂等
- API/数据兼容与迁移
- 输入校验、最小权限、密钥和日志脱敏
- 结构化日志、指标、追踪和关联 ID
- 测试层级、测试数据和不稳定测试治理
- 依赖锁定、许可证和漏洞扫描
- 复杂度预算：复用优先、抽象和公开接口的准入条件、无关重构限制
- 格式化、lint、类型检查、测试、构建与 CI
- 例外审批、存量基线、责任人和复审周期

每项规范至少回答：规则是什么、为何需要、如何自动检查、如何申请例外。
