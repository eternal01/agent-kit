# 完成前验证

## 证据门禁
1. 把准备声明的每项结果改写成可验证条件。
2. 为每个条件选择直接证据：测试、构建、静态检查、原问题复现、diff 或逐条需求核对。
3. 运行当前环境中完整且最新的命令；读取退出码、失败数和关键输出，不依赖旧结果或他人结论。
4. 对文档和计划检查链接、占位符、结构及需求覆盖；Skill 变更还要检查触发契约。无自动化检查时执行人工清单并明确说明。
5. 静态验证只能证明其覆盖范围；涉及触发或交互行为时记录是否做过真实 Agent 回放。
6. 证据不支持时报告实际状态、失败和未验证项，不使用“应该、看起来、可能已完成”。
7. 证据支持时连同命令和结果摘要一起给出结论。

常见声明与证据见[验证矩阵](references/matrix.md)。部分验证只能证明其覆盖范围，不得外推为全部通过。
