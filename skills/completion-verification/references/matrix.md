# 验证矩阵

| 声明 | 直接证据 | 不能替代 |
|---|---|---|
| 测试通过 | 当前完整测试命令退出 0、失败数为 0 | 旧输出、只跑单测子集 |
| 构建成功 | 当前构建命令退出 0 | lint 或测试通过 |
| 缺陷修复 | 原复现不再出现且回归测试通过 | 代码已修改 |
| 可合并 | 需求核对、相关检查通过、无阻塞审查项 | diff 看起来合理 |
| 文档可用 | 链接/命令/示例检查及受众清单 | 拼写检查 |
| 计划完整 | 逐条需求映射、依赖顺序与命令检查 | 章节齐全 |

报告格式：
```markdown
## 验证
- `<命令或检查>`：通过/失败；<关键结果>
## 未验证
- <项目及原因>
## 结论
- <仅陈述证据支持的范围>
```
