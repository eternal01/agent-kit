# 实施计划模板

```markdown
# <主题>实施计划

## 目标与依据
- 需求/设计：<路径或链接>
- 完成条件：<可验证结果>

## 全局约束
## 影响文件与职责
## 任务
### 任务 1：<可独立验证的交付物>
- 文件：`path`
- 依赖：
- 接口变化：
- 步骤：
  1. 建立失败测试/基线证据。
  2. 完成最小实现。
  3. 更新必要配置、迁移或文档。
- 验证：`具体命令`
- 预期：<可观察结果>
- 回滚：<动作或不适用原因>

## 发布/迁移顺序
## 风险与监控
## 需求覆盖检查
```

任务以交付物划分；省略不适用字段，不填写“待定”。
