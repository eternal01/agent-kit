# 笔记形态

按用途选择一种主结构，不要求每篇笔记包含所有章节。

## 快速知识点

适合一个概念或一次发现，通常 300～800 字：

```text
标题 → 一句话结论 → 例子或反例 → 适用边界 → 来源
```

## 学习文章

适合系统学习：

```text
学习目标 → 前置知识 → 核心模型 → 推导或示例 → 常见误解 → 练习 → 延伸阅读
```

## 来源笔记

适合文章、仓库、论文或讨论：

```text
来源信息 → 原文主张 → 我的理解 → 尚未核验 → 可应用场景
```

不要把原文摘要写成自己的结论。

## 对比笔记

适合方法或技术比较：

```text
问题和硬约束 → 比较维度 → 证据 → 适用条件 → 暂定结论 → 复审触发条件
```

## 个人反思

记录经历、理解变化和待验证判断。个人观点应以第一人称或明确标签呈现，不伪装成通用事实。
