# 安全发现格式

```markdown
## <标题>
- 严重度：critical | high | medium | low
- 状态：confirmed | needs-validation
- 位置：<文件、接口或边界>
- 前置条件：<攻击者需要具备什么>
- 证据：<可复现事实>
- 影响：<可达资产和范围>
- 现有控制：<已确认的保护>
- 反证结果：<尝试排除问题的结果>
- 建议：<最小修复或验证动作>
- 覆盖限制：<未检查内容>
```

严重度由可利用性和影响共同决定。无法确认入口、权限或数据敏感度时使用 `needs-validation`，不要用高等级代替不确定性。
