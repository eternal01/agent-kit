# 安全评审清单

仅检查与范围有关的项目。

- 身份来源是否可信；认证失败是否关闭访问。
- 授权是否在资源和操作边界执行，而非只在界面执行。
- 外部输入是否在解析后、使用前验证；不同组件是否采用相同解释。
- URL、文件路径、重定向和网络访问是否限制目标范围。
- 密钥是否避开仓库、日志、错误、缓存和子进程参数。
- 多租户、并发和异步任务是否保持数据与权限隔离。
- 重试、超时、取消和降级是否会绕过控制或重复副作用。
- 第三方依赖、安装脚本、构建产物和发布权限是否可追溯。
- 审计日志是否足以还原高风险操作，同时不记录敏感正文。
- 备份、撤销、密钥轮换和事故恢复是否实际可执行。
