# 威胁模型

按实际系统选择，不要求填满模板。

## 范围

- 资产：数据、身份、密钥、计算资源、发布权限和业务能力。
- 主体：用户、管理员、服务账户、外部系统和攻击者。
- 边界：网络、进程、租户、权限域、部署环境和组织边界。
- 入口：API、消息、文件、CLI、Webhook、依赖、构建和运维通道。

## 滥用路径

对每条路径写清：

```text
攻击者能力 → 入口 → 被绕过的控制 → 可达资产 → 影响 → 可观察证据
```

重点检查：

- 身份混淆、越权和跨租户访问
- 注入、解析差异和不可信内容执行
- 密钥泄露及日志、缓存、错误信息暴露
- 重放、竞态、幂等失效和状态回滚
- 失败开放、危险默认值和降级绕过
- 构建脚本、安装脚本、依赖和发布链
- 资源耗尽、费用滥用和恢复路径

## 反证

高风险候选至少检查一个反证：入口是否可达、控制是否真实生效、数据是否敏感、攻击者是否具备前置能力、影响是否被隔离。反证失败才提升为确定发现。
