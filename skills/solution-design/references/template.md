# 功能方案模板

```markdown
# <方案名称>
## 背景与问题
## 目标与非目标
## 用户/系统场景与验收标准
## 约束、假设与待确认项
## 最小路径检查（不改变、配置、复用、局部扩展）
## 方案比较与推荐（存在实质取舍时）
| 路径 | 满足目标与局限 | 改动面与成本 | 风险、验证与回滚 | 适用条件 |
|---|---|---|---|---|
| 最小化改动（配置/复用/局部修改） | | | | |
| 折衷方案 | | | | |
| 长期目标最优方案（注明优化目标） | | | | |

给出推荐及切换条件；不可行的档次写明原因，不虚构候选。
## 职责、接口与数据流
## 异常处理与边界情况
## 测试策略
## 风险与后续工作
```

只保留与当前方案有关的章节。简单改动可在对话中使用同样结构，不创建文件。
