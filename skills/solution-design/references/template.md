# 功能方案模板

```markdown
# <方案名称>
## 背景与问题
## 目标与非目标
## 用户/系统场景与验收标准
## 约束、假设与待确认项
## 最小路径检查（不改变、配置、复用、局部扩展）
## 功能行为比较与推荐（存在实质取舍时）
| 可行路径 | 场景与验收覆盖 | 体验与改动成本 | 风险与验证 | 适用条件 |
|---|---|---|---|---|
| <一种可行路径；每种路径单独一行> | | | | |

给出推荐、切换条件及必要的回滚考虑；不可行的路径写明原因，不虚构候选，也不在此拆分编码任务。
## 职责、接口与数据流
## 异常处理与边界情况
## 测试策略
## 风险与后续工作
```

只保留与当前方案有关的章节。简单改动可在对话中使用同样结构，不创建文件。
