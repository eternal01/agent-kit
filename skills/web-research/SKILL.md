# Web 技术调研

## 流程
1. 把问题拆成可核验的主张，确定所需时效和证据标准。
2. 优先官方文档、标准、发行说明、安全公告和源码；社区内容仅作补充。
3. 搜索时限定产品、版本和日期；读取原文上下文，不依据摘要下结论。
4. 对关键结论至少交叉核验；若只能找到单一来源，明确置信度。
5. 记录标题、URL、发布日期/更新时间和访问日期；区分来源事实、推断和建议。
6. 遇到登录墙、动态页面或访问失败时说明限制，不虚构内容。
7. 输出直接回答问题的结论，并附紧邻结论的引用和仍待验证项。

查询策略与证据等级见[调研准则](references/research-guide.md)。不得在命令、URL 或输出中泄露凭据。
