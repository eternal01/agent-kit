# 调研准则

## 来源优先级
1. 标准组织、厂商官方文档、发行说明、安全公告、许可证原文。
2. 官方源码、问题跟踪器和维护者声明。
3. 可信技术机构或作者的一手测量。
4. 社区问答、博客和聚合内容。

低优先级来源不能覆盖更高优先级的一手事实。涉及“当前、最新、支持、价格、安全”时必须核对发布日期和适用版本。

## 记录格式
```markdown
- 结论：<直接回答>
- 证据：[标题](URL)，发布/更新于 YYYY-MM-DD，访问于 YYYY-MM-DD
- 适用范围：<版本、平台、地区>
- 置信度：高 | 中 | 低
- 限制：<冲突或缺失>
```

引用应支持紧邻的结论；搜索结果摘要只用于定位原文。
